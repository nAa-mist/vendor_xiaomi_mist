# Xiaomi Redmi Note 17 5G (mist) — device-specific vendor additions

This repository is intended for `vendor/xiaomi/mist` in a LineageOS 24.0 source checkout.

## Important separation

- [Device tree](https://github.com/nAa-mist/device_xiaomi_mist) owns BoardConfig, device product, overlays and mist-specific VINTF.
- [Research archive](https://github.com/nAa-mist/mist-bringup) retains the complete original 29-commit history and stock inspection metadata.
- **Common SM4450 proprietary blobs** currently belong to the upstream `vendor/xiaomi/sm4450-common` vendor tree generated by the [xiaomi-ravelin SM4450 common extractor](https://github.com/xiaomi-ravelin/android_device_xiaomi_sm4450-common).
- This repo is reserved for truly **mist-only** proprietary files and device overlays; none are verified and extracted yet.

## Current files

`proprietary-files.txt` is intentionally empty until additional mist-only paths are verified.
`mist-vendor.mk` and `BoardConfigVendor.mk` are no-op integration scaffolds, not compiled vendor binaries.

No proprietary Xiaomi binaries or stock firmware are published here. The reference Global
`WPUMIXM` firmware is not proven compatible with the customized `WPUMIDC.C11` phone.
